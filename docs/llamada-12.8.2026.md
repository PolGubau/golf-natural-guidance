
Resumen
La reunión revisó una propuesta de software personalizado para la academia mediante la demostración de funciones clave.

Demostración de propuesta técnica
Se presentó un prototipo con gestión de reservas y panel administrativo para optimizar la operativa interna. El sistema centralizará procesos de pago, facturación y registro de usuarios.

Requerimientos de gestión integral
El desarrollo cumplirá con normativas fiscales y liquidaciones para múltiples entidades empresariales. Se definieron flujos para el manejo de alumnos, consentimiento digital y automatización de reportes contables.

Propuesta económica y operativa
La inversión inicial se estableció en 7000 euros con una cuota mensual de mantenimiento de 200 euros. Se acordó la migración de datos y soporte para futuras integraciones tecnológicas.


Decisiones
Acordada
Pago online obligatorio para reservas Se establece el pago online obligatorio para todas las reservas efectuadas a través de la web, eliminando la opción de pago en persona para estas transacciones.
Confirmaciones vía Email y WhatsApp Las notificaciones de confirmación de reserva se enviarán a los clientes utilizando tanto el canal de correo electrónico como el de WhatsApp.
Implementación del sistema Verifactu El sistema se diseñará para soportar el cumplimiento de la normativa Verifactu antes de que finalice el año.
Facturación automática profesor-alumno El software generará automáticamente las facturas del profesor al alumno en el momento en que se confirme la reserva o el pago.
Gestión centralizada de leads mediante etiquetas Los leads provenientes de diferentes sitios web (General, Ebooks, Mallorca Golf Experience) se centralizarán en un mismo software, utilizando etiquetas para clasificar su origen y producto.
Control de acceso basado en roles Se implementará un sistema de control de acceso por roles, donde los administradores visualizarán la totalidad de los datos y los profesores tendrán acceso restringido únicamente a sus propias clases y calendarios.
Confirmación manual de pagos offline Para las sesiones reservadas y pagadas en la oficina, el sistema incluirá un flujo de trabajo manual donde el personal administrativo marcará la sesión como "pagada" para activar la generación de la factura.
Gestión anual de consentimientos digitales Se implementará un flujo de trabajo digital recurrente para gestionar la aceptación anual de consentimientos requeridos por la normativa de protección de datos y menores.
Costes de inteligencia artificial definidos El cliente asumirá directamente el pago de los costes de consumo de la inteligencia artificial, mientras que la empresa desarrolladora se encargará de su configuración técnica.
Integración de facturación con A3 Se acuerda que el software generará automáticamente los archivos de facturas y cobros en el formato A3 requerido por la asesoría.
Estrategia de migración de datos Se incluye la migración de datos en el precio de la instalación, sujeto a la calidad y formato del archivo exportado del sistema anterior.

Detalles
Presentación y objetivo de la reunión: Toni Planells Golf y Nicolás Loprete Ferrazzano se reúnen con Pol Gubau Amores y Gerard Martinez para evaluar una propuesta de software de gestión personalizada para su academia de golf. Toni Planells Golf explica que están entrevistando a proveedores de software tras contactar con Pol Gubau Amores y Gerard Martinez a través de Instagram, con el objetivo de obtener una solución técnica que mejore su operativa actual (00:02:43).
Demostración visual del prototipo: Pol Gubau Amores presenta una demo inicial del software, explicando que la solución constará de dos partes diferenciadas: un sistema de reservas para el usuario final y un panel administrativo para la gestión interna. La demostración busca ilustrar cómo se vería el flujo de trabajo tanto para el cliente que desea contratar una clase como para el administrador que gestiona los datos (00:08:59).
Proceso de reserva para usuarios: Pol Gubau Amores detalla el flujo de reserva, diseñado para ser sencillo y accesible. El sistema permite seleccionar categorías como "Clases Privadas", "Cursos y Actividades" o "Junior Academy", facilitando que el usuario vea la disponibilidad de horarios antes de elegir un profesor, o que pueda buscar directamente a un profesor específico si ya conocen sus preferencias (00:10:17) (00:12:11).
Selección de profesor y precios: Nicolás Loprete Ferrazzano aclara que el precio de las clases varía según el profesor y la duración del producto seleccionado. Pol Gubau Amores confirma que la interfaz mostrará el precio final de manera clara antes de que el usuario proceda a la confirmación, brindando transparencia al proceso de selección (00:13:29).
Gestión de datos de usuario y registro: Pol Gubau Amores explica que, para agilizar las reservas, el sistema permitirá a los usuarios iniciar sesión con su cuenta de Google, cargando automáticamente nombre, teléfono y correo electrónico. Para la facturación, los datos fiscales faltantes como el NIF o la dirección se podrán ingresar manualmente una sola vez y quedar guardados para futuras ocasiones (00:14:13).
Flujo de pagos y notificaciones: Se establece que el sistema gestionará los pagos online directamente a través del servidor del banco. Una vez completado el pago, el software confirmará la reserva enviando un aviso por correo electrónico y, opcionalmente, vía WhatsApp, incluyendo la opción de añadir el evento al calendario del usuario (00:15:38) (00:17:44).
Panel de administración (Backoffice): Pol Gubau Amores muestra el panel de control para el administrador, que incluye gráficos de estadísticas y un resumen general de próximas clases y facturación pendiente. Este panel permite gestionar reservas, descargar facturas en formato PDF y realizar un seguimiento completo de las actividades (00:17:02).
Integración con Verifacto: Nicolás Loprete Ferrazzano y Gerard Martinez discuten la necesidad de implementar el sistema de facturación electrónica Verifacto, asegurando que el software estará preparado para esta normativa antes de finales de año, lo cual es un requisito esencial para la operación de la academia (00:19:35).
Gestión de facturación del profesor: Pol Gubau Amores y Nicolás Loprete Ferrazzano acuerdan que, en el modelo actual de la academia, el profesor emite la factura directamente al alumno. El sistema automatizará este proceso enviando la factura al profesor y al alumno tras realizarse la clase o el pago, simplificando la carga administrativa (00:20:24).
Control de agenda y trazabilidad: Pol Gubau Amores presenta el módulo de agenda, donde los administradores podrán visualizar todas las actividades y el estado de las reservas. Nicolás Loprete Ferrazzano enfatiza la necesidad de contar con un registro detallado de cada cliente, incluyendo el histórico de clases realizadas y gastadas, para mejorar la gestión de relaciones con los alumnos (00:21:22).
Estrategia de captación de leads y segmentación: Nicolás Loprete Ferrazzano explica que utilizan tres sitios web distintos para diferentes productos (una web genérica, otra para libros electrónicos y suscripciones, y una landing page exclusiva para "Mallorca Golf Experience"). Acuerdan centralizar toda la información en el nuevo software, utilizando etiquetas para identificar el origen de cada cliente, lo que permitirá segmentar campañas de marketing de forma más eficiente (00:23:07).
Automatización de procesos: Nicolás Loprete Ferrazzano expresa su deseo de automatizar el seguimiento de clientes que no responden tras dos días o que llevan meses inactivos, mediante el envío automático de correos electrónicos. Pol Gubau Amores y Gerard Martinez proponen implementar estas automatizaciones de forma gradual, comenzando por las funciones esenciales y añadiendo reglas de negocio conforme sea necesario (00:27:39).
Integración con el bot de WhatsApp: Nicolás Loprete Ferrazzano describe que actualmente utiliza un sistema llamado Signal Core (por el cual paga unos 70€ mensuales) para gestionar su bot de WhatsApp y un agente de voz, pero tiene dificultades para integrar estos servicios con su software actual para agendar clases directamente. Pol Gubau Amores y Gerard Martinez proponen conectar este sistema mediante la Interfaz de Programación de Aplicaciones (API) del nuevo software o migrar la funcionalidad al propio sistema que desarrollarán (00:31:31).
Propiedad y escalabilidad del software: Nicolás Loprete Ferrazzano plantea la posibilidad de comercializar este software a otras academias de golf en el futuro, contando con Pol Gubau Amores y Gerard Martinez para el soporte técnico. Se acuerda configurar el sistema para permitir esta modalidad, incluyendo opciones para gestionar cancelaciones según la política de la academia (24 o 48 horas) y habilitar la generación de facturas solo tras el pago en caja (00:43:37).

Pol Gubau Amores confirma que integrarán una función para que los clientes acepten estos términos digitalmente dentro del software y que el sistema solicite la renovación de dicho consentimiento una vez pase un año (00:50:45).

Gerard Martinez y Pol Gubau Amores se comprometen a documentar la lógica exacta de estas transacciones y asegurar que el sistema permita generar estas liquidaciones automáticas, cumpliendo con los requisitos legales necesarios para los autónomos (00:52:06).
Requisito de firmas digitales: Al concluir, Nicolás Loprete Ferrazzano reitera que, para cumplir con Verifacto y la emisión de facturas por parte de cada profesor, será necesaria la integración de las firmas digitales de los profesionales dentro del sistema, punto que queda anotado para el desarrollo (00:57:12).

Pol Gubau Amores y Gerard Martinez respondieron que, al tratarse de un desarrollo a medida, pueden implementar funciones como la integración con Google Calendar y asegurar que la interfaz sea clara e intuitiva para que cada profesor pueda acceder únicamente a su información relevante (00:59:17).
